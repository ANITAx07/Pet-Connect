# PetConnect 🐾

A full-stack pet adoption platform built with the **MERN stack**. Admins manage pet listings and approvals; users can browse pets, request adoptions, donate supplies, and track requests in real time.

Built for **CSE470: Software Engineering — Summer 2025**, BRAC University.

## Features

- Browse, search, and filter pets
- Favorite pets & request adoption
- **Track adoption request status** (pending/approved/rejected)
- Donate pet supplies
- Pet social feed (posts, likes, comments)
- Real-time notifications
- Profile management & secure password reset
- Downloadable adoption certificate (PDF)
- Admin panel: add/manage pets, approve/reject requests & donations

## Tech Stack

**Frontend:** React.js, Material-UI
**Backend:** Node.js, Express.js
**Database:** MongoDB (Mongoose)
**Auth:** JWT

## Setup

```bash
git clone https://github.com/ANITAx07/CSE470_Project-.git
cd CSE470_Project-

# Backend
cd backend
npm install

# Frontend
cd frontend
npm install
npm start         # http://localhost:3000
```
